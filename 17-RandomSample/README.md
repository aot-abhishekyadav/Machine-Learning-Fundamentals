# Random Sample Imputation

This project demonstrates **Random Sample Imputation**, a technique for handling missing values by replacing them with randomly selected existing values from the same column.

### Topics Covered

* Random Sample Imputation for numerical data
* Distribution and variance comparison
* Covariance and correlation analysis
* Random imputation for categorical data
* Handling missing values in the Titanic and House Prices datasets

### Advantages

* Preserves the original data distribution relatively well
* Better preserves variance than mean imputation
* Simple to implement
* Works with numerical and categorical data

### Disadvantages

* Results can change due to randomness
* Reproducibility can be an issue
* May affect relationships between features
* Can introduce outliers
* Not ideal when a large percentage of values are missing

### Datasets

* Titanic Dataset
* House Prices Dataset
