# Date & Time Feature Engineering with Pandas

This project demonstrates how to work with **Date and Time data using Pandas** and extract useful features for data analysis and machine learning.

## 📌 Topics Covered

* Converting columns to `datetime`
* Extracting:

  * Year
  * Month & Month Name
  * Day
  * Day of Week
  * Week Number
  * Quarter
  * Semester
  * Weekend indicator
* Calculating time differences
* Calculating differences in:

  * Days
  * Months
  * Minutes
  * Hours
  * Seconds
* Extracting time components such as:

  * Hour
  * Minute
  * Second
  * Time
* Basic date/time feature engineering using `pandas` and `numpy`

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook

## 🎯 Purpose

The project helps understand **date and time feature engineering**, which is commonly used in **Data Analysis, EDA, and Machine Learning**.
